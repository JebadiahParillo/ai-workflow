# ai-workflow

My personal, evolving AI coding workflow for Claude Code: an eight-stage
loop from idea to shipped, built on
[Matt Pocock's skills](https://github.com/mattpocock/skills), with extra
stages, model choices per stage, and a token budget.

- [WORKFLOW.md](WORKFLOW.md): the stages, the checklist, the token budget and the lessons so far.
- [skills/](skills/): proposed skills that fill the gaps. They are drafts (v0): each says what it should do, and gets refined after use.
- [CHANGELOG.md](CHANGELOG.md): how the workflow has changed, one entry per retro.

## Use

Install Matt Pocock's skills first. Then copy the folders in `skills/` into
`~/.claude/skills/` (or a project's `.claude/skills/`) and follow WORKFLOW.md.
